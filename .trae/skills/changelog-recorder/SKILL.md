# 变更记录器 Skill

## 功能概述

本 skill 用于记录对 `.trae/` 目录下所有配置文件的变更，确保每次修改都有记录可追踪。

## 使用时机

在以下情况后，立即调用此 skill：

1. ✅ 修改了规则文件 (`rules/`)
2. ✅ 修改了 skill 文件 (`skills/`)
3. ✅ 修改了配置文件 (`config.yml`、`prompts/` 等)

## 执行步骤

### 第一步：检测变更 🔍

1. **检查 Git 状态**
   - 查看当前有哪些文件变更
   - 识别新增、修改、删除的文件
2. **检查变更范围**
   - 只关注 `.trae/` 目录下的变更
   - 忽略其他目录

### 第二步：收集变更信息 📝

向用户确认以下信息：

1. **修改原因**
   - 简单描述为什么做这些变更
2. **补充细节**
   - 是否需要补充每个文件的变更细节？

### 第三步：生成变更记录 ✍️

按照 `CHANGELOG.md` 的格式，在文件顶部添加新的变更记录。**增加一项新修改的记录，不是修改老的记录过得**

记录结构：

```markdown
## YYYY-MM-DD-HH-MM

### 修改时间
{当前时间}

### 修改原因
{用户提供的原因}

### 修改内容
- [文件1](相对路径) - {变更类型}
  - {变更详情}
- [文件2](相对路径) - {变更类型}
  - {变更详情}
```

### 第四步：完成提示 ✅

告知用户变更记录已保存，并询问是否需要：

- 提交到 Git？
- 其他操作？

## 变更类型

| 类型 | 说明 |
|-----|------|
| 新增 | 创建新文件 |
| 更新 | 修改现有文件内容 |
| 删除 | 删除文件 |
| 重命名 | 文件改名 |
| 清理 | 移除冗余内容 |

## 项目配置

- 变更记录文件：`.trae/CHANGELOG.md`
- 关注目录：`.trae/`
- 日期格式：YYYY-MM-DD
