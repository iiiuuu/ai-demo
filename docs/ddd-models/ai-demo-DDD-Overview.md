
# ai-demo - DDD设计总览

## 1. 项目概述
本项目是一个外卖/电商平台，实现订单履约流程。核心是订单的全生命周期管理，包含支付、库存、物流等业务流程的集成。

## 2. 限界上下文划分

| 限界上下文 | 主要职责 | 包含聚合 | 状态 |
|---------|---------|--------|------|
| **订单履约** | 订单全生命周期管理，状态流转，金额计算 | 订单 | NEW |
| **库存** | 库存扣减、释放、查询 | 库存 | NEW |
| **支付** | 支付处理，支付结果回调 | 支付记录 | NEW |
| **商品** | 商品信息管理，价格查询 | 商品 | NEW |

## 3. 上下文映射

### 3.1 订单履约 &lt;-&gt; 库存
- **关系**：客户-供应商
- **集成方式**：领域事件
  - `OrderPlacedEvent` → 库存扣减
  - `OrderCancelledEvent` → 库存释放

### 3.2 订单履约 &lt;-&gt; 支付
- **关系**：客户-供应商
- **集成方式**：领域事件
  - `PaymentSucceededEvent` → 订单状态变更
  - `PaymentFailedEvent` → 订单取消

### 3.3 订单履约 &lt;-&gt; 商品
- **关系**：客户-供应商
- **集成方式**：同步查询
  - 商品信息查询（价格、库存）

## 4. 关键领域概念总结

### 核心聚合根
- **订单(Order)**：订单履约上下文的核心，包含状态机、金额计算、履约流程

### 核心领域事件
- **OrderCreatedEvent**：订单创建
- **OrderPaidEvent**：订单支付成功
- **OrderShippedEvent**：订单发货
- **OrderDeliveredEvent**：订单确认收货
- **OrderCancelledEvent**：订单取消
